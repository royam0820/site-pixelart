## 1. 🌈 La véritable histoire du « Code Konami » (`↑ ↑ ↓ ↓ ← → ← → B A`)

### D'où vient le nom « Konami » ?
Le nom vient de **Konami**, un célèbre studio japonais de jeux vidéo fondé en 1969 (qui a créé des jeux cultes comme *Castlevania*, *Contra*, *Metal Gear*, *Frogger* ou encore *PES / eFootball*).

### L'histoire de sa création par erreur (1985–1986)
- En **1985**, le développeur japonais **Kazuhisa Hashimoto** devait adapter sur la console **Nintendo NES** le jeu de tir spatial ***Gradius***, qui était sorti à l'origine sur borne d'arcade.
- **Le problème** : le jeu était tellement dur que même lui, le développeur, mourait sans arrêt et n'arrivait pas à tester les niveaux suivants !
- **L'astuce** : pour gagner du temps pendant ses tests, il a programmé une combinaison secrète de touches très facile à retenir sur une manette Nintendo :
  > **⬆️ Haut, ⬆️ Haut, ⬇️ Bas, ⬇️ Bas, ⬅️ Gauche, ➡️ Droite, ⬅️ Gauche, ➡️ Droite, B, A**
- Dès qu'il tapait ce code, son vaisseau recevait instantanément toutes les armes et tous les boucliers au maximum.
- **L'oubli légendaire** : quand le jeu est sorti en magasin en **1986**, Kazuhisa Hashimoto a **oublié d'effacer ce code de test** !

### Comment c'est devenu le code le plus célèbre du monde
- Les joueurs ont découvert le secret par hasard et se sont mis à se l'échanger dans toutes les cours de récréation.
- En **1988**, Konami l'a remis volontairement dans le jeu d'action ***Contra*** (où le code donnait **30 vies** au lieu de 3 !), puis dans des dizaines d'autres jeux.
- Aujourd'hui, le **Code Konami** est un clin d'œil universel chez les créateurs de jeux et de sites web. On le voit même dans le film d'animation *Les Mondes de Ralph* (*Wreck-It Ralph*) !

### Comment l'utiliser sur le site de Maxence ?
1. **Au clavier** : tape successivement `↑ ↑ ↓ ↓ ← → ← → B A` sur n'importe quelle page du site.
2. **À la souris / sur téléphone** : clique sur `Code Secret : ↑↑↓↓←→←→BA` tout en bas de la page ou sur le bouton `🌈 Activer Mode Rainbow` dans le Niveau 4.
3. **Effet** : tout le site passe en **Mode Rainbow Overdrive** pendant 10 secondes avec une mélodie 8-bit, des confettis pixel, **+25 XP** et le badge **🌈 Maître Konami** !

## 2. 🥚 D'où vient le mot « Easter Egg » (Œuf de Pâques) ?

Dans un jeu vidéo ou un site web, un **Easter Egg** est une fonction cachée, une blague ou un secret que le créateur a dissimulé exprès pour récompenser les joueurs curieux (comme chercher des œufs en chocolat cachés dans le jardin à Pâques).

- **Le tout premier Easter Egg de l'histoire du jeu vidéo** date de **1980** dans le jeu ***Adventure*** sur la console Atari 2600 : à l'époque, l'entreprise Atari refusait d'écrire le nom des développeurs sur les boîtes de jeux. Le programmeur **Warren Robinett** a donc caché un passage secret invisible qui menait à une salle affichant en clignotant : *« Created by Warren Robinett »* !

### Les Easter Eggs cachés dans le site de Maxence :
1. **🕺 La Danse Pixel** : cliquer **5 fois** sur l'avatar de Maxence le fait danser (+15 XP & badge *Danseur Pixel*).
2. **🌈 Le Code Konami** : active le mode arc-en-ciel pendant 10 secondes (+25 XP & badge *Maître Konami*).
3. **💎 Le Coffre au Trésor Secret** : caché dans le coin sombre de la salle du Boss Final (+25 XP & badge *Chasseur de Trésor*).
4. **🕵️ Le Fait Absurde** : caché parmi les 5 faits fun du Niveau 1 (+15 XP & badge *Détective Fun*).

## 3. 🎵 Le son « 8-bit » (Chiptune) & l'effet « CRT »

- **Pourquoi dit-on « musique 8-bit » ?**
  Dans les années 1980, les consoles (comme la NES ou la Game Boy) avaient si peu de mémoire qu'elles ne pouvaient pas enregistrer de vraies chansons MP3. Elles utilisaient une petite puce électronique (*sound chip*) qui fabriquait des notes géométriques en direct (ondes carrées et triangulaires).
  👉 *Sur le site de Maxence, c'est exactement pareil : il n'y a aucun fichier audio MP3 ! C'est le navigateur qui synthétise les sons 8-bit en direct grâce à la technologie `Web Audio API`.*

- **C'est quoi les petites lignes horizontales sur l'écran (CRT Scanlines) ?**
  Avant les écrans plats d'aujourd'hui, on jouait sur de grosses télévisions à **tube cathodique (CRT)** et sur des bornes d'arcade. Le faisceau lumineux balayait l'écran ligne par ligne, ce qui créait ces fines lignes horizontales appelées *scanlines* !
